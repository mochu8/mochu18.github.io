# mochu8.github.io

`mochu8` 的个人技术博客，使用 Jekyll 构建并部署在 GitHub Pages。

## 本地运行

需要 Ruby、Bundler 和 Git。

```bash
bundle install
bundle exec jekyll serve
```

浏览器访问 `http://127.0.0.1:4000/`。

## 内容结构

- `_posts/`：已发布文章
- `_drafts/`：草稿
- `_layouts/` 与 `_includes/`：页面模板
- `public/`：样式、脚本和图片
- `telegram-tools.html`：Telegram 机器人工具箱
