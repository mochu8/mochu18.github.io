这个博客已经托管在 GitHub Pages 上一段时间，但仓库里仍然保留着旧站点的作者信息、社交账号、统计代码和外部资源地址。页面表面上可以访问，实际维护起来却有不少隐患：身份信息不统一、部分脚本已经失效，历史图片也依赖一个随时可能停止服务的 CDN。

这次更新的目标很明确：让站点真正属于 `mochu8`，同时把它整理成一个可以继续写文章、维护工具和稳定发布的技术博客。

<!-- more -->

## 统一站点身份

首先处理的是页面上直接展示的身份信息。

- 站点标题和作者统一为 `mochu8`
- GitHub 链接改为 [mochu8](https://github.com/mochu8){:target="_blank" rel="noopener noreferrer"}
- 使用 GitHub 公开头像作为站点头像和浏览器图标
- 删除旧的 Twitter 展示、头像、文字 Logo 和相册页面
- 重写“关于”页面和项目介绍

身份替换并不意味着可以修改所有历史内容的署名。旧文章中的项目链接、引用和作者表述仍按原文保留，仓库中的许可证信息也没有被改写。站点身份与历史内容归属是两件事，维护时必须把这条边界说清楚。

## 让资源回到仓库

旧文章共有 83 张正文图片依赖外部对象存储。如果只删除 `cdnurl` 配置，这些文章会立即出现大量断图。

这次更新先将图片迁移到仓库，再把文章中的引用改为 Jekyll 提供的 `relative_url`：

```liquid
![示例图片]({{ "/public/images/mountains.jpg" | relative_url }})
```

这样做有两个好处：

1. 图片与文章一起接受 Git 版本管理。
2. GitHub Pages 会通过 HTTPS 提供资源，不再依赖旧域名和失效的 TLS 配置。

迁移完成后，对所有站内资源引用进行了扫描，确认发布页面没有缺失文件。

## 清理旧的前端依赖

原站点加载了 jQuery、InstantClick、Highlight.js、Fancybox、第三方访问统计和评论脚本。其中一些文件没有实际用途，另一些引用路径已经失效。

Jekyll 已经使用 Rouge 在构建阶段生成代码高亮，因此浏览器端不需要再加载一份 Highlight.js。标签和分类页面也可以由 Liquid 直接生成，无需 jQuery 插件参与。

清理后，普通博客页面只保留必要的样式和移动端抽屉脚本。与此同时还修复了这些模板问题：

- 无效的 Liquid 统计模板
- 分类页错误的脚本地址
- 页面布局中多余的闭合标签
- 分页链接没有使用站点相对路径
- 导航按钮缺少无障碍标签
- 中文标签和分类锚点无法稳定跳转

减少依赖不只是为了缩小页面体积，更重要的是降低长期维护成本。

## 重写 Telegram 机器人工具箱

[Telegram 机器人工具箱]({{ "/telegram-tools.html" | relative_url }}) 原来依赖一个并不存在的 jQuery 地址，所以页面虽然能够打开，按钮实际上无法正常工作。

这次将交互逻辑改成了原生 JavaScript，并重新整理了界面。现在它可以完成：

- Bot Token 格式解析
- Webhook 请求地址生成
- MarkdownV2、HTML 和 JSON 文本转义
- Telegram 内联键盘 JSON 生成

安全方面也做了调整。用户输入不再通过 `innerHTML` 拼接到页面，而是使用 `textContent` 创建结果节点，降低输入内容触发脚本注入的风险。Token 在结果中默认脱敏，只有执行复制操作时才使用完整内容。

```js
const code = document.createElement("pre");
code.textContent = result;
```

整个工具只在当前浏览器内处理输入，不会主动上传 Token 或消息文本。

## 发布与验证

更新完成后，代码直接推送到 `master` 分支，由 GitHub Pages 自动构建。

除了确认构建状态为成功，还对线上首页、关于页、项目页、工具页、样式文件、头像和历史文章图片进行了实际请求检查，关键资源均正常返回。同时复查了 Dependabot，当前没有开放的安全告警。

这次整理没有引入新的框架，也没有为了“现代化”而重写整个博客。现有 Jekyll 结构足够完成内容发布，真正需要解决的是身份、依赖、资源和维护边界问题。

## 接下来

站点基础已经稳定下来，后续更新会集中在两件事上：继续整理可复用的小工具，以及记录真实的开发和维护过程。

比起一次做出复杂的系统，我更希望这个博客保持简单、可读，并且每次更新都能留下清楚的原因和结果。
